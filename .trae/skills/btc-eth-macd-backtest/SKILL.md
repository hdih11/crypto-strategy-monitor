# BTC/ETH MACD 二次交叉形态回测

固定流程，用户给出周期/止损/盈亏比后直接跑脚本，不要重写引擎。

## 运行

```powershell
python .trae/skills/btc-eth-macd-backtest/scripts/macd_backtest.py --timeframe 1h --sl 0.01 --tp 0.02 --days 90
```

参数：`--timeframe` 15m/1h/4h/1d，`--sl` 止损，`--tp` 止盈，`--days` 天数，`--symbols` 交易对列表，`--tag` 输出文件名标记。输出 `macd_backtest_<tag>_report.txt` 和 `_result.png` 到当前目录。

## 规则（已与用户确认，勿擅改）

- 做多：DIF 零轴水下 金叉1→死叉→金叉2，且金叉2的DIF值高于金叉1；做空：水上反向对称。DIF越过零轴形态重置。**金叉2无论是否满足 DIF2>DIF1 都成为新一轮金叉1**（信号可连续触发），金叉2触发后形态不重置——重写状态机时容易漏掉这条导致信号变少。
- 每币独立 1000U，固定 100U 保证金，100x，全仓；手续费 0.04%/边；资金费 0.01%/8h 按周期折算（多付空收）。
- 数据源 `data-api.binance.vision`（用户网络下 OKX/Binance 主站不通，此镜像可直连）；超 1000 根自动分页。
- 纯现货不能做空/加杠杆，本流程是现货行情上的杠杆模拟，回复用户时必须说明。

## 关键口径（教训，违反会导致结果错误）

- 出场顺序：每根K线比较止损价与强平价谁离入场更近，连续走势先触更近者；仅开盘跳空越过才滑点/强平；同根K线触止损与止盈按止损。禁止固定"先强平后止损"。
- 全仓强平距离随权益缩水变近，必须逐根用当前权益算强平价。
- 一次只改一类参数（周期/止损/盈亏比），保持其余冻结，否则无法归因。
- 最大回撤用 `(equity - cummax)/cummax`，输出为负值百分比。
